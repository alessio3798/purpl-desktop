# PURPL for Windows

This repository only hosts the installers and release notes for the PURPL desktop app. The app's source code is not here.

Download the app from **https://purpl.app/download**.

The app updates itself from the releases published here. Each release lists the commit of the PURPL web app it bundles.

Questions and bug reports: use the help link inside the app, or the contact page on purpl.app.
